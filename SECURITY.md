# Security

Please do not open a public issue for a security-sensitive report.

This project does not process credentials or customer data by design. If you find
a vulnerability, report it privately to the repository maintainer with:

- a minimal reproduction;
- affected version/commit;
- expected impact.

Preferred private channel: use GitHub Security Advisories for this repository
if available. If not available, open a minimal public issue asking for a private
contact channel without including vulnerability details, secrets, or personal data.

Do not include real customer data, personal information, annual reports, or
credentials in reports. Use synthetic reproductions only.

See [docs/PRIVACY.md](docs/PRIVACY.md) for the data boundary.
